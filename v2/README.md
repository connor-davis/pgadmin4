# pgAdmin 4 — v2 (Electrobun + ShadCN + TanStack Router)

A modern rewrite of the pgAdmin 4 desktop UI using:

- **[Electrobun](https://blackboard.sh/electrobun/)** — native desktop runtime (replaces Electron)
- **[ShadCN](https://ui.shadcn.com/)** — React component library with Tailwind CSS
- **[TanStack Router](https://tanstack.com/router)** — file-based routing
- **[TanStack Query](https://tanstack.com/query)** — data fetching & caching
- **Vite** — frontend bundler

The existing Flask backend (`web/pgAdmin4.py`) is reused unchanged.

---

## Requirements

- [Bun](https://bun.sh/) >= 1.0
- Python with pgAdmin 4 dependencies installed (see `../requirements.txt`)

## Setup

```bash
cd v2
bun install
```

Copy the dev config template and set your Python path:

```bash
cp dev_config.json.example dev_config.json
# Edit dev_config.json and set pythonPath to your venv python
```

**`dev_config.json` (gitignored):**
```json
{
  "pythonPath": "C:/path/to/venv/Scripts/python.exe",
  "pgadminFile": "C:/path/to/pgadmin4/web/pgAdmin4.py"
}
```

## Development

```bash
bun run dev
```

This:
1. Builds the Vite SPA once (generating `routeTree.gen.ts` and `dist/`)
2. Starts Vite in watch mode (rebuilds on file changes)
3. Starts Electrobun in dev/watch mode (relaunches the app on source changes)

For HMR (instant React updates without full rebuild):

```bash
bun run dev:hmr
```

## Build

```bash
bun run build
```

## Adding ShadCN Components

```bash
cd src/mainview
bunx shadcn add button
bunx shadcn add card
bunx shadcn add dialog
# etc.
```

## How Flask Port is Passed to the Renderer

The main process (`src/bun/index.ts`) finds an available port, starts Flask, then loads the webview with the port as a URL query parameter:

```
views://mainview/index.html?pgPort=5050&pgKey=<uuid>
```

The renderer reads this via `new URLSearchParams(window.location.search)` in `lib/api.ts`.
